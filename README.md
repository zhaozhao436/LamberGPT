# LamberMed：知识注入增强的中文医学大语言模型

**论文：LamberMed: A Chinese Medical Large Language Model with Knowledge Injection**

LamberMed 基于 **Llama-3.1-Base-8B**，通过医学知识图谱注入、双向知识增强和高质量指令微调，提升中文医学知识理解与医学自然语言处理能力。本页介绍论文的方法、数据构建、训练设置与实验结果。

| 项目 | 内容 |
| --- | --- |
| 基础模型 | Llama-3.1-Base-8B |
| 预训练语料 | CMED，约 **65B tokens / 202 GB** |
| 指令数据 | CMEDPROMPT，质量筛选后 **1,172,553** 条 |
| 训练阶段 | 全参数持续预训练 → 全参数监督微调 |
| 模型版本 | LamberMed-Base、LamberMed-Chat |
| 评估范围 | 医学知识问答、临床文本处理、信息抽取、医学伦理问答、双向知识泛化 |

## 研究动机

中文医学大模型需要充分、准确的领域知识。仅依赖医学指令微调，难以系统补充预训练阶段缺失的知识；直接使用知识图谱三元组进行单向学习，又可能出现“反转诅咒”（reversal curse）：模型能回答某个事实的正向表述，却不能正确回答其语义一致的反向表述。

LamberMed 围绕三个问题展开研究：

- **如何高密度注入医学知识？** 将大规模医学知识图谱及其自然语言表述融入持续预训练。
- **如何改善反向知识泛化？** 为同一事实构建医学语义一致的正向和反向表述。
- **如何衔接预训练与指令学习？** 从预训练语料构建来源一致的指令，并对全部指令进行质量筛选。

## 方法

### 1. 医学知识注入

使用 CPubMed-KG 中超过 **410 万条三元组、175 万个实体和 40 余类关系**，通过人工设计的规则将结构化知识转写为自然语言，与医学文献、临床记录、教材、指南等语料共同用于持续预训练，得到 **LamberMed-Base**。

例如，将“疾病—影像检查—检查项目”三元组转写为包含实体类型和关系含义的完整描述，使模型同时学习结构化事实及其语言表达。

### 2. 双向知识增强

对知识图谱事实及其来源文本构建双向表达，减少模型对知识学习方向的依赖。

| 表述方向 | 示例 |
| --- | --- |
| 正向 | 疾病 A 的治疗方案包括药物 B。 |
| 反向 | 药物 B 可用于治疗疾病 A。 |

这里的“对称”指**同一医学事实的双向语言表述**，不意味着原始关系在数学意义上对称，也不意味着可以直接交换任意三元组的头尾实体。反向表达需保持医学逻辑与原事实语义一致。

### 3. 来源一致的指令构建

从 CMED 中的指南等材料提取知识片段，使用人工模板生成问题，由 GPT-4 根据片段生成答案，再通过自然语言推断（NLI）检查答案能否由片段支持，并迭代修正。

CMEDPROMPT 同时包含来源于 CMED 的指令和公开指令，覆盖问答、诊疗、多轮对话、安全问答及医学 NLP 任务。使用 Qwen-72B 按逻辑性、正确性、冗余程度和是否偏题等维度进行 1–5 分质量评估，过滤 1–3 分样本，最终保留 **1,172,553 条**指令，对 LamberMed-Base 进行监督微调，得到 **LamberMed-Chat**。

来源一致性用于提高指令与预训练知识的衔接程度；它不等同于保证模型已掌握所有相关知识。

## 数据构建

### CMED：持续预训练语料

CMED 总规模约 **202 GB、650 亿 tokens**，包含中文和英文医学知识，以及通用和安全语料。

| 数据来源 | 主要内容 | 规模 |
| --- | --- | ---: |
| CPubMed-KG | 医学三元组及自然语言表达 | 2 GB |
| 双向知识增强语料 | 正向、反向医学事实表达 | 1.25 GB |
| 中文医学文献 | 医学全文与摘要 | 35.61 GB |
| 临床记录 | 中英文临床文本 | 110.94 MB |
| 教材与临床指南 | 医学教材、考试资料和指南 | 429.73 MB |
| 医学指令集合 | 高质量医学指令 | 5.38 GB |
| 通用语料 | 百科、网页等通用中文文本 | 49.22 GB |
| 安全语料 | 安全与伦理相关文本 | 19.46 MB |
| PubMed Central | 英文医学文献 | 104 GB |
| UMLS | 医学定义与知识三元组 | 4 GB |

语料经过清洗、去重、格式规范化、损坏文本剔除和语言过滤。各来源规模按论文统计列示，总量为近似值。

### CMEDPROMPT：监督微调数据

- **来源于 CMED 的指令**：基于预训练材料构建问答、诊疗、多轮对话和安全问答。
- **公开指令**：补充医学与通用问答、诊疗及 NLP 任务。
- **统一质量筛选**：对两类来源均进行二次质量评估，最终保留约 117 万条样本。

## 训练与评测设置

| 设置 | 持续预训练 | 监督微调 |
| --- | --- | --- |
| 初始化模型 | Llama-3.1-Base-8B | LamberMed-Base |
| 训练数据 | CMED | CMEDPROMPT |
| 训练方式 | 全参数、下一词预测 | 全参数监督微调 |
| 学习率 | 5 × 10⁻⁵ | 1 × 10⁻⁵ |
| 序列长度 | 4096 tokens | 4096 tokens |
| 输出模型 | LamberMed-Base | LamberMed-Chat |

持续预训练使用 AdamW、BF16 混合精度和 **24 张 NVIDIA A800 GPU**，耗时约 **315 小时**。

论文采用统一的 **3-shot** 评测设置。确定性任务使用贪心解码；EthicQA 使用 temperature = 0.1、top-p = 0.9，在三个随机种子下报告 BLEU 均值与标准差；最大生成长度为 512 tokens。以下结果均来自论文实验，LamberMed 对应最终的 Chat 模型。

## 实验结果

### 公开医学任务

C-Eval_med、CMMLU_med 为论文选取的医学子集，MedQA_ch 为中文子集。除 TCMM 使用 Micro-F1 外，其余任务使用准确率；表中数值按百分制报告，粗体为该列最优。

| 模型 | C-Eval_med | CMMLU_med | MedQA_ch | MDCFNPC | CTS | TCMM |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| ChiMed-GPT-13B | 31.58 | 24.86 | 23.85 | 12.52 | 1.67 | 14.58 |
| HuatuoGPT2-13B | 73.68 | 52.97 | 21.42 | 4.00 | 1.33 | 1.80 |
| MedicalGPT-13B | 52.63 | 29.19 | 22.53 | 8.00 | 1.33 | 26.06 |
| Llama-3.1-Base-8B | 68.42 | 47.03 | 41.74 | 13.00 | 19.56 | 7.41 |
| GPT-4 | **78.95** | **61.62** | **64.42** | 59.00 | 48.67 | 55.52 |
| **LamberMed-8B** | **78.95** | 53.65 | 57.91 | **63.00** | **54.67** | **67.98** |

在上述六项任务中，LamberMed 在 MDCFNPC、CTS 和 TCMM 上高于 GPT-4，在 C-Eval_med 上与其持平，在 CMMLU_med 和 MedQA_ch 上位居第二。结果反映论文所比较模型与评测设置下的表现。

### 私有医学任务

LiverNER 和 LiverRE 基于经临床医生修订的 **4,702 条肝病相关三元组**构建，相关三元组及来源文本从预训练和微调语料中排除。EthicQA 包含 **2,345 组医学伦理问答**。

| 模型 | LiverNER（Micro-F1） | LiverRE（Micro-F1） | EthicQA（BLEU） |
| --- | ---: | ---: | ---: |
| ChiMed-GPT-13B | 15.53 | 1.29 | 2.33 ± 0.18 |
| HuatuoGPT2-13B | 1.95 | 7.81 | 8.55 ± 0.34 |
| MedicalGPT-13B | 18.28 | 8.72 | 21.98 ± 0.52 |
| Llama-3.1-Base-8B | 1.39 | 12.70 | 14.05 ± 0.47 |
| GPT-4 | 49.06 | 24.50 | 15.67 ± 0.41 |
| **LamberMed-8B** | **70.41** | **65.50** | **23.04 ± 0.39** |

EthicQA 还进行了 GPT-4o 评审与人工评估。人工评估抽取 100 个样本，每个答案由三位评估者独立按 1–10 分评分后取平均；LamberMed 得分为 **8.35**，GPT-4 为 **8.28**。

### 双向知识泛化

使用 OpenCMKG 构建 **1,428 对正反向判断题**，其中 714 对为正确事实、714 对为错误事实。下表分别报告正向准确率、反向准确率及二者的绝对差值。

| 模型 | 正向准确率（%） | 反向准确率（%） | 差值（百分点）↓ |
| --- | ---: | ---: | ---: |
| ChiMed-GPT-13B | 29.60 | 20.08 | 9.52 |
| HuatuoGPT2-13B | 56.70 | 50.37 | 6.33 |
| MedicalGPT-13B | 39.10 | 29.53 | 9.57 |
| Llama-3.1-Base-8B | 50.56 | 46.61 | 3.95 |
| GPT-4 | **69.56** | **65.99** | 3.57 |
| **LamberMed-8B** | 63.50 | 61.89 | **1.61** |

LamberMed 的正反向差值最小，表明其对提问方向的敏感性较低；GPT-4 在两种方向的绝对准确率上仍然最高。差值需要与准确率结合解读。

## 消融与补充分析

### 双向增强的独立作用

使用 **5% 的 CMED**，仅进行持续预训练、不进行 SFT，比较单向和双向知识增强。单向版本通过重复正向表达匹配 token 数量，其余数据、初始化和训练设置一致，实验使用三个随机种子。

| 评测集 | 知识增强方式 | 正向准确率（%） | 反向准确率（%） | 差值（百分点）↓ |
| --- | --- | ---: | ---: | ---: |
| CPubMed-KG 留出集（500 对） | 单向 | 53.83 | 44.30 | 9.53 |
| CPubMed-KG 留出集（500 对） | 双向 | 53.27 | 48.91 | **4.36** |
| OpenCMKG 跨图谱集（1,428 对） | 单向 | 52.77 | 43.96 | 8.81 |
| OpenCMKG 跨图谱集（1,428 对） | 双向 | 52.14 | 47.92 | **4.22** |

控制语料规模后，双向增强提高了反向准确率并缩小正反向差距。这组实验使用缩小的训练规模，其绝对结果不宜与完整模型直接比较。

### 指令质量与通用能力

使用 **1,172,553 条筛选后指令**的模型，在论文报告的九项任务上均优于使用 **300 万条未筛选指令**的对照模型。例如，C-Eval_med 从 72.63 提升至 78.95，LiverRE 从 60.50 提升至 65.50。

在完整通用基准上，LamberMed 的表现与基础模型接近：

| 模型 | C-Eval_all | CMMLU_all |
| --- | ---: | ---: |
| Llama-3.1-Base-8B | 51.56 | 52.79 |
| LamberMed-8B | 51.40 | 52.47 |

## 局限与使用边界

本研究主要在基准任务上验证模型能力，尚不能据此推断真实临床环境中的诊疗效果。知识图谱和文献主要基于截至 2024 年的数据，可能存在知识过时、偏差或错误；双向知识增强也不能弥补所有未被训练语料覆盖的知识。

**LamberMed 用于科研探索，不能替代专业医务人员的临床判断，不应直接用于临床诊疗决策。** 各数据来源及基础模型的使用仍需遵守其原始许可和授权条件。
